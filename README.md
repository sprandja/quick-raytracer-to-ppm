# quick-raytracer-to-ppm
This project is an extended version of a basic raytracer originally created by Scratchapixel, modified to include polymorphic objects, bounding-box cube intersections, and would add more.

Compile the cpp file with compiler of choice. Running the program will create a file with ".ppm" extension with the rendered objects. You can specify the objects, add objects or modify their attribute values in the main function objects vector.
